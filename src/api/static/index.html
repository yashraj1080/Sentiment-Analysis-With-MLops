🔄 End-to-End MLOps System Architecture

CI/CD Lifecycle on AWS Cloud

Every model enhancement or code commit automatically executes testing, container packaging, registry upload, and zero-downtime rolling deployment to AWS ECS Fargate containers.

Dataset & NLP

STAGE 02
FastAPI Service

STAGE 03

Slim container packaging with healthchecks
STAGE 04
GitHub Actions
CI linting, 18 unit tests, & ECR image push
STAGE 05
ECS Fargate
Serverless container execution behind ALB
STAGE 06
CloudWatch & Drift
Continuous telemetry & confidence degradation alerts
⚠️ Model Drift Detection Simulation (Phase 5 Feature)

In production MLOps, models experience data drift or concept drift when incoming customer text deviates from the training distribution. This interactive test feeds anomalous / out-of-distribution queries into the pipeline and evaluates shifts in prediction entropy and confidence distributions.
